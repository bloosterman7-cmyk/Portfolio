## 📊 Featured Projects (Top 3 Showcase)

### 1. Telecom Operational Optimization & Inefficiency Modeling
*   **Business Problem:** CallMeMaybe needed an analytical system to detect underperforming operators affecting customer retention and network capacity.
*   **Data Used:** 50,000+ call records, client subscription dates, and operational metrics.
*   **Methodology & Tools:** Python (Pandas, SciPy, Seaborn). Implemented a robust **80/20 Percentile Model** to isolate operator inefficiency while neutralizing system outliers. Validated findings using a parametric **Two-Sample T-Test** on customer waiting times.
*   **Key Results:** Confirmed with statistical significance ($p < 0.05$) that underperforming operators caused systematic delays, providing managers with an automated operational framework to trigger targeted interventions.
*   **View Code:** [View Telecom Analysis](./Telecomunicaciones.ipynb)

### 2. E-Commerce Analytics, Cohort Retention & Marketing Optimization
*   **Business Problem:** Y.Afisha required a diagnostic audit to evaluate user engagement, lifetime value (LTV), and marketing return on investment (ROMI).
*   **Data Used:** Server logs (visits), transaction history (orders), and marketing spend dataset.
*   **Methodology & Tools:** Python (Pandas, Matplotlib). Structured **Time-Based Cohort Analysis** to track user retention. Calculated dynamic Customer Acquisition Cost (CAC) and ROMI using Pandas Period formatting to map time-series trends.
*   **Key Results:** Identified the exact month where marketing sources started showing diminishing returns, allowing a 15% budget reallocation toward higher-retaining user segments.
*   **View Code:** [View Business Analysis](./AnálisisDeNegocio.ipynb)

### 3. Customer Churn Prediction & Predictive Grouping (Model Fitness)
*   **Business Problem:** A gym chain needed to anticipate client cancellation trends to deploy proactive retention campaigns.
*   **Data Used:** User profiles, monthly attendance logs, and promotional contract histories.
*   **Methodology & Tools:** Python (Scikit-Learn). Applied supervised **Machine Learning (Logistic Regression / Random Forest)** to predict churn probability and unsupervised **K-Means Clustering** to segment users by behavioral density.
*   **Key Results:** Mapped 5 distinct user profiles, isolating the exact behavioral thresholds (attendance drops below 2x/week) that signal a 70% probability of churn.
*   **View Code:** [View Model Fitness Machine Learning](./ModelFitness.ipynb)
